About this concept

How it is organised

A small taxonomy tags every course by role, level, competency, product area and learning moment, so each person gets their own path and certifications map to competencies.

How it stays current

An n8n workflow reads new releases, finds the courses whose product area changed, drafts the updates per role for human review and republishes this page.
